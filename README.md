# Python Challenge

Projeto com desafios de código para praticar Python e Engenharia de IA.

## Arquivos

- `challenge1.py`: mostra a primeira e a última acurácia, o total de itens e a média de uma lista com 3 valores.
- `challenge2.py`: com uma lista de 5 acurácias, calcula a média, a melhor e a pior acurácia (em %). Depois percorre as rodadas e marca ✅ quando a acurácia está na média ou acima dela, e ❌ quando está abaixo.

## Como executar

Requer Python 3.6 ou superior (por causa das f-strings).

```bash
python challenge1.py
python challenge2.py
```
